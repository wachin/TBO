# TBO — Historical application (legacy)

> [!NOTE]
> This document describes the **legacy** C/GTK 3 application and the transition
> to the Python/PyQt6 rewrite. The active implementation lives at the repository
> root and its documentation is in [`README.md`](README.md). The legacy C/GTK
> source is kept under [`legacy/`](legacy/).

TBO is a free comic editor built around pages, panels, text, images, and SVG
artwork. This repository contains the historical C/GTK 3 application and
**TBO 2**, an active reimplementation in Python and PyQt6.

> [!IMPORTANT]
> TBO 2 is under development. It can already open, edit, and save historical
> documents, but it has not yet reached full feature parity with TBO 1.0. Keep
> a backup of your projects and use **Save As** while testing it.

## Project status

TBO 1.0 had been unmaintained since 2013. Instead of directly porting its
obsolete GTK APIs, TBO 2 rebuilds the application around a testable architecture
while preserving compatibility with the original `.tbo` format.

TBO 2 currently supports:

- creating, opening, and saving `.tbo` documents;
- reading numbers and projects generated by TBO 1.0;
- atomic saves that prevent partially written files;
- creating, deleting, navigating, and reordering pages;
- creating, selecting, moving, resizing, cloning, and deleting panels;
- entering a panel and moving, cloning, or deleting its text, images, and SVGs;
- adding new text with a selected font and color;
- importing raster images and SVG files into a panel;
- undoing and redoing the editing operations implemented so far;
- navigation, fit-to-window, and zoom controls;
- detecting pending changes before creating, opening, or closing a document;
- displaying missing resources without crashing the application.

Features still pending include:

- resizing, rotating, and flipping objects;
- editing text and color properties;
- exporting to PNG, PDF, and SVG;
- automatic recovery, translations, and distribution packages.

See [ROADMAP.md](ROADMAP.md) for the modernization phases, priorities, and exit
criteria.

## Requirements

- Python 3.11 or later;
- PyQt6 6.6 or later;
- pytest and pytest-qt to run the test suite.

The historical implementation has a different set of dependencies and is kept
as a reference. It is not required to run TBO 2.

## Running TBO 2

The easiest option is to use the launcher from the repository root:

```bash
./tbo.sh
```

You can pass a document path to open it directly, even when running the launcher
from another directory:

```bash
/path/to/TBO/tbo.sh /path/to/comic.tbo
```

Run directly from the repository without installing the package:

```bash
PYTHONPATH=src python3 -m tbo
```

To open a historical project directly:

```bash
PYTHONPATH=src python3 -m tbo data/tut.tbo
```

You can also install the project in editable mode from the repository root:

```bash
python3 -m pip install -e '.[dev]'
tbo data/tut.tbo
```

## Basic usage

- `Ctrl+N`, `Ctrl+O`, `Ctrl+S`: create, open, and save a document.
- `PageUp` / `PageDown`: navigate between pages.
- `Ctrl+Shift+N`, `Ctrl+Delete`: create or delete pages.
- `F`, `Ctrl+D`, `Delete`: create, clone, or delete the selected panel.
- Arrow keys: move the selection in 5-pixel increments.
- `Ctrl+Z` / `Ctrl+Shift+Z`: undo or redo.
- `+`, `-`, `1`, `2`: zoom in, zoom out, actual size, and fit to window.
- Double-click a panel: edit its objects.
- `Esc`: return from object editing to the page.

See [README.md](README.md) for the detailed guide and complete keyboard
shortcut reference.

## Tests

Run the suite from the repository root:

```bash
QT_QPA_PLATFORM=offscreen python3 -m pytest
```

The suite includes unit tests for the model and commands, invalid parser cases,
round-trip tests using the historical tutorial, atomic-save tests, and headless
Qt interface integration tests.

## Repository layout

```text
.
├── src/             # Active Python/PyQt6 implementation
├── tests/           # Unit and integration tests
├── data/            # Doodles, icons, tutorial, and other resources
├── packaging/       # Flatpak, .desktop and build helpers
├── legacy/          # Historical C/GTK 3 implementation
│   ├── src/
│   ├── po/
│   ├── doc/
│   └── test/
└── ROADMAP.md       # Recovery and modernization plan
```

In `src/`, the document model is independent of the widgets. The canvas
represents that model through `QGraphicsScene`, while mutations are recorded as
commands in a `QUndoStack`. The parser treats every `.tbo` file as untrusted
input and applies limits before constructing the document.

## Contributing

The most useful contributions at this stage are small changes accompanied by
tests. Before changing persistence or compatibility behavior:

1. add a fixture or test case that describes the expected behavior;
2. keep the model—not the graphical items—as the source of truth;
3. verify that opening, saving, and reopening preserves the document;
4. run the complete test suite in headless mode;
5. update the roadmap or documentation when the scope changes.

Do not combine large formatting changes, refactors, and new features in a single
change. Keeping them separate makes the recovery of this historical codebase
easier to review.
